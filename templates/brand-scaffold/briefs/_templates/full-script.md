## The viewer's journey
Where the viewer starts (the header's "Awareness") and where the script has to get them before the
product appears. A cold viewer moves one step at a time: unaware → problem aware → solution aware →
product aware. Name the step each section moves them to.

**Bring the product in as late as the script allows**, once the viewer knows the problem and what
kind of solution fixes it. Introducing it earlier, to beat the drop-off curve, reaches more people
who aren't ready to buy. The warmer the viewer (product aware, retargeting), the earlier it can come.

- **The bridges** (rows 2 and 7) are where good ads break: a strong hook followed straight by "Brand X
  is the answer" feels like a switch from content to a sales pitch. Each bridge is one line that
  carries the hook's promise into the body, or the body's payoff into the ask
- **A curiosity gap** opened in the hook is closed late, not in the next sentence
- **Contrast lines** ("it's not X, it's Y") at most once: they are the most common AI-script tell

## Hooks
The hook is a promise that what follows is relevant to this viewer, not a trick to stop the scroll.
Write at least five, each a different type, and record each as a separate take so the editor can
build variations without a reshoot (it costs minutes on set).

| | Type | Line | Visual (first frame) | On-screen text |
|---|---|---|---|---|
| A | | | | |
| B | | | | |
| C | | | | |
| D | | | | |
| E | | | | |

Types to pick from: problem named, contrarian truth, specific proof (a real number or time frame),
curiosity gap, uncomfortable truth about price or the category, "a friend calling you out",
texture/ASMR (no words, 2-3 s), founder's story with real stakes, social proof. Only what the
evidence and `brand-lens.md` support.

Check each hook for: **clarity** (a stranger gets it in 3 seconds), **relevance** (names the
problem the persona has; a bare persona callout, "Moms of toddlers, listen up", is weaker than their
problem, and Meta reads the words to decide who to show it to), **novelty** (not the hook everyone
in the category runs), **specificity** (a number, a name, an outcome) and **credibility** (usually
visual: who is on screen). Two or three done well is enough.
