# set-up-brain: feedback log

What we've observed on real runs. A log, not a rulebook. A lesson moves into SKILL.md or the
onboarding runner only after it has held on a second brand.

## Open checks before the next new brand

- **First briefs in week one** (added Oct 2026, from a shared post about a strategist's first
  week): on the next new brand, run a fast lane beside the full build and aim for 5 briefs in
  market inside week one. The lane: read the reviews, map every ad the brand ran in the last 12
  months by angle, hook and format, name the angles never tested that come straight from review
  language, then write 5 briefs, each with a hypothesis and the review it traces to. The fast lane
  skips the roadmap stop, so tell the brand that up front and keep the briefs inside the brand lens
  and the claims rules. At day 30, record for each brief: did it run, how it did against the
  account's winners, and whether the full build's roadmap would have picked the same angle. Keep it
  if it pays on two brands; drop it if not
