# Feedback log

What we've observed running the weekly leaderboard: which tags told us something, where names broke,
whether ranking by tag changed what we made next. A log, not a rulebook: new lessons land here with a
date, and once one has held on a second brand it moves into `SKILL.md` or a process file (factory
rule 6), leaving one line here saying where it went. Brand-specific lessons go in the brain's
`running-notes/feedback.md`. No brand details here.

## Open tests

- **2026-11-07, does ranking by angle change what the next batch contains?** The claim behind this
  skill is that a weekly board ranked by angle, persona, awareness and format makes the next batch
  start from what won, not what someone liked (Stated, a practitioner's post, Nov 2026, no data).
  The test, on the first two brands that run it for four weeks: for each week, write down the batch
  the team planned before reading the board and the batch made after it. Count how many ads moved

  the moved ads beat the rest. If nothing moves in four weeks, the board is a report, not a loop:
  say so here and rethink step 4 of `weekly-leaderboard.md`
