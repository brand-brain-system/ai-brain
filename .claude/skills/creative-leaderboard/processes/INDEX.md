# Creative leaderboard: process index

- **weekly-leaderboard**: pull the last 7 and 28 days at ad level, run the script, read the tables, write the takeaways (what won by angle, persona, awareness, format, voice and shape, plus the hit rate) and route the next batch to `iterations` and `angle-bank`. Pick for the weekly run and for "which angles won".
- **naming-setup**: first run on an account. Check how the account names ads, then adopt the factory convention or write the brand's field map in `running-notes/ad-naming.md`, and make a CSV of suggested names for the team to apply by hand. Stops before anything changes in the account.
- **name-audit**: list the ads whose names don't parse, with the reason and the spend on each, and suggest the fixed name. Pick when names look off or the board misses spend.
