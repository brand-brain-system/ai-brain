# Improve the factory: process index

Run them in this order. Each one names its output; the next one starts from it.

- **intake-sources**: Take what the owner hands in (pasted posts, prompts, screenshots, links, PDFs, videos), save working copies in the scratchpad, split each source into its distinct claims, one line each.
- **map-against-factory**: Check every claim against the factory and classify it: covered, partly covered, new, or conflicts. The output is a coverage table with the file for each.
- **decide-homes**: Pick the one home for each item (definition, method doc, skill, process, pointer, brain template, script, or open test), sort rules from methods to try, ask the owner the few real questions. Ends at a stop: the owner approves the plan.
- **build-with-agents**: Write the shared contract file, then run parallel builders that each own their own files and return proposed edits to existing files. Holds the builder brief template.
- **wire-and-release**: The full wiring and release checklist, from catalog rows to the tag. Ends at a stop before the tag.
- **visual-map**: Update and republish the workflow page when the release changed how the work flows.

A small change (one pointer, one summary fix) can skip build-with-agents and go from decide-homes straight to wire-and-release. It still gets a release.
