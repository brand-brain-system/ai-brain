# The plan's shape (`strategy/growth-plan.md`)

Frontmatter: `generated_on`, `refresh_by` (90 days later), `approved_by`, `approved_on`.

1. **The short version.** The goal and the number it's judged by, the three bets in one line each,
   the first two weeks. Written so it can be pasted into an update to the owners
2. **Where we stand.** The rubric scores as a table (stage, row, score, one line of evidence, label),
   the weighting and why, the unit economics with sources and windows, what is Data-limited
3. **The three bets.** For each: the weak stage it fixes, the mechanism in one sentence, the
   evidence, cost, the first proof point and its date, and the roads not taken
4. **90 days.** A table: week, move, stage, owner, skill (or "task for <person>"), leading
   indicator, kill criterion, check date. Grouped as unblock (1-2), foundation (3-6), pace (7-12),
   with the season calendar beside it
5. **12 months.** One block per quarter: milestone, bet, what must be true to move on, the season
6. **Plays to skip.** Each with the reason (evidence, budget, Danish rules, capacity)
7. **Open questions.** What the brain doesn't know yet, each linked to an open loop or a line in
   `running-notes/missing-context.md`
8. **Method notes.** Docs read with dates, numbers and their sources, what the human corrected
