# harvest-ideas: feedback log

What we've observed on real runs. A log, not a rulebook. A lesson moves into SKILL.md or a process
only after it has held on a second brand.

## Open checks before the first real run

- **"How did they notice it worked?"** (added Oct 2026, from a shared prompt hack): in the
  customer-language lens, search the reviews for the moment a customer says *how* they first noticed
  the product working, especially the indirect signal: someone else noticed first, a photo
  comparison, a professional's comment, a side effect they didn't expect. Log each moment as an entry
  with the review quoted as its source. Review-sourced only: never invent a moment the reviews don't
  contain, because an imagined "my doctor noticed" is an unbacked claim. First runs should record how
  many entries this produced that the lens would have missed, how many survived `evaluate-ideas`, and
  whether the moments were filmable by a creator. Keep it if it pays on two brands; drop it if not
