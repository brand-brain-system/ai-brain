# Iterate Landing Page: how to use it

Use this skill when a landing page already exists and you want a new version built from a specific direction. Give it the page and say what should change. The existing page becomes the baseline; there is no template picker.

## Run it

Say: `Iterate this landing page: <file, folder, or URL>. Direction: <what should change>.`

The skill will:

1. preserve an untouched baseline and capture it on desktop and mobile;
2. turn your direction into a precise change-and-preserve plan;
3. show material copy changes beside the original copy for approval;
4. build a separately named version without overwriting the original;
5. compare the new version to the baseline and test it in a browser;
6. send the page itself for review, revise it, and hand off the approved version with QA and a change receipt.

Use `new-landing-page` when there is no existing page and you want to build from the landing-page template library.

## Shared utilities

This skill shares screenshot, browser-QA, comparison, voice-lint, and grounding utilities with the sibling `new-landing-page` skill. It does not use that skill's templates, swipe file, picker, or run initializer. Install both sibling skill folders together.
