# Process: refresh (the DNA exists)

**Accomplishes:** the brain's DNA brought up to date without redoing the research.
**Select when:** `brand-context/brand-one-pager.md` exists. **Not when:** the brain has no DNA (`research.md`).
**Inputs:** the brain's `sub-context-docs/brand-profile-narrative.md`, `brand-lens.md` and `sub-context-docs/visual-vocabulary.md` and the date of the last export.
**Output:** a short working file `audits/<YYYY-MM>/brand-dna-research-<YYYY-MM-DD>-refresh.md` with only the changes, then `write-up.md`.

Never reuse one brand's DNA for another brand: a new brand always gets `research.md`.

## Steps
1. **Ask once** (clients only): "Same offer, products and look as on <date of last export>?" A yes with nothing new: check only steps 2-3
2. **Recheck what changes most:** the proof numbers on the site (review count, rating), the current offer and prices, the announcement bar, new products or packaging, and the brand's live ads in the Meta Ad Library (new formats or a new look)
3. **Recheck the visual system only on a signal:** a relaunch, a new site design, a new agency credit, or ads that no longer match the prompt modifier
4. **Write only the deltas** to the working file: field, old value, new value, source, date, label

## Quality checks
- Every changed proof number has a new source and date; the old value stays in the working file for the record
- If the visual system changed, the prompt modifier is rewritten, not patched

## Stop when
The deltas are written; then `write-up.md` steps 1, 3 and 4 (and step 2 if the look changed).
