# Global knowledge

Generalised lessons promoted from real work. A lesson arrives here only after it has held on a second brand, has had the brand's details removed, and has its source named (a test, a course session, a
person). One file per topic; each file starts with a two-line digest and ends with "Where this came from".

Raw transcripts and third-party text do not belong here: write the idea, credit it, label it *Stated* until a test has confirmed it.
